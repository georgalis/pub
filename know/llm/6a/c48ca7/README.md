# Parabolic Syllogism

Withhold the conclusion, and the reader supplies it. A writing style that
argues by premise and momentum: examples converge on a point the text
never states, a deliberately remote metaphor turns out to carry the
argument, and the reader arrives at an insight that feels found rather
than told. Turned inward, the same method pushes synthesis past the
obvious answer toward conclusions no one planned.
